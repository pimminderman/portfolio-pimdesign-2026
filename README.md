# Pim Minderman — Product Design Portfolio

A static portfolio site presenting selected product design work across sustainability data, AI insights, and supply-chain security.

## Contents

- `index.html` — the portfolio website
- `assets/` — project videos and the preview icon

## Preview locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

Upload `index.html` and the contents of `assets/` to the root of your GitHub repository. Then go to **Settings → Pages** and publish from the `main` branch, using the `/ (root)` folder.
